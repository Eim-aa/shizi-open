# 拾字 · 公开数据（Shizi open data）

This repository publishes the parts of the Shizi (拾字) iOS app that their licenses require to be freely available:

- `data/<字>.json` — stroke data used by the app (Arphic Public License / SIL OFL; see `data/LICENSE.md`).
- `data/etymology.json` — character-origin notes (Apache-2.0 / LGPL-3.0-or-later records; see `data/LICENSE.md`).
- `notices/arphic-modification-notices.json` — how and when the modified Arphic-derived files were changed.
- `licenses/` — full license texts.

The Shizi app's own source code is not published here. Each app release has a matching tag in this repository.

本仓库只放许可证要求公开的笔顺与字源数据及许可文本；拾字 App 本身的代码不在这里。每个 App 版本在这里有对应的标签。
